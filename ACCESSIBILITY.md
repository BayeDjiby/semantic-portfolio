# Accessibility Audit & Compliance Report

This document outlines the accessibility audit performed on the [Personal Portfolio Website](https://baye-semantic-portfolio.netlify.app/) using Google PageSpeed Insights (Lighthouse).

---

## 1. Audit Overview
* **Tool Used:** Google PageSpeed Insights (Lighthouse)
* **Achieved Score:** 95 / 100
* **Status:** Ready for submission.

---

## 2. Identified Findings & Completed Fixes
* **Color Contrast:** Verified text and background color combinations for primary sections.
* **Semantic Structure:** Ensured proper heading hierarchy and landmark regions across the layout.
* **Interactive Elements:** Validated keyboard tab-indexes and focus behavior for navigation links and project cards.
